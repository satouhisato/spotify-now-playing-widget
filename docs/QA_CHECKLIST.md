# QA Checklist

Spotify接続、表示、配布物に関係する変更後に使用する確認項目です。変更内容に関係する項目を実施してください。

## 自動確認

- [ ] プロジェクト直下で `npm.cmd run build` が成功する。
- [ ] `src-tauri`で `cargo test --locked` が成功する。
- [ ] Rust変更後に `cargo fmt --check` が成功する。
- [ ] `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`のバージョンが一致している。

## 初回接続

- [ ] Spotify Developer DashboardのRedirect URIが `http://127.0.0.1:43821/callback`になっている。
- [ ] Client IDを入力して「Spotifyに接続」を押すとブラウザが開く。
- [ ] Spotifyで許可すると接続完了ページが表示され、ウィジェットへ曲情報が反映される。
- [ ] 認証を拒否・中断した場合に、アプリが終了せず接続エラーを表示する。
- [ ] 認証情報やトークンがプロジェクト内へ生成されていない。

## 再生情報

- [ ] 曲名、アーティスト名、ジャケット画像が正しい。
- [ ] 曲を変更すると、おおむね4秒以内に表示が更新される。
- [ ] 長い曲名とアーティスト名だけがマーキー表示になる。
- [ ] 一時停止中はウィジェットが薄く表示される。
- [ ] 再生中の曲がない場合に状態メッセージが表示される。
- [ ] 再生を再開すると、再接続操作なしで曲表示へ戻る。
- [ ] アプリを再起動しても、保存済みトークンで曲情報を取得できる。
- [ ] トークン更新後もSpotifyへ再ログインせず取得を継続できる。

## ウィンドウ操作と見た目

- [ ] ウィジェットが常に最前面に表示される。
- [ ] タスクバーに通常のアプリボタンが表示されない。
- [ ] インストール版をスタートメニューから起動してもPowerShellやコンソール画面が表示されない。
- [ ] ボタン、入力欄、リサイズ領域以外をドラッグして移動できる。
- [ ] 高さを72〜180 pxの範囲で変更できる。
- [ ] 288 pxの固定幅でレイアウトが崩れない。
- [ ] ジャケット、背景、文字、閉じるボタンが各サイズで欠けない。
- [ ] 長い文字の流れるアニメーションに不自然な飛びがない。
- [ ] 閉じるボタンで正常に終了できる。

## 配布用ビルド

- [ ] `npm.cmd run tauri build` が成功する。
- [ ] `src-tauri/target/release/bundle/`にMSIまたはセットアップEXEが生成される。
- [ ] 既存の実行中アプリを閉じてから、新しいビルドをインストールできる。
- [ ] インストール版が起動し、接続・曲表示・ドラッグ・常に最前面が動作する。
- [ ] インストール版の初回起動後、Windowsの自動起動一覧に登録される。
- [ ] Windowsへ再サインインすると、PowerShellを介さずウィジェットが自動起動する。
- [ ] アンインストール後に実行ファイルが削除される。
- [ ] トークンを残すか削除するかが、配布方針どおりになっている。
