# QA Checklist

## 自動確認

- [ ] `npm.cmd run build`が成功する。
- [ ] `src-tauri`で`cargo fmt -- --check`が成功する。
- [ ] `src-tauri`で`cargo test --locked`が成功する。
- [ ] `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`のバージョンが一致する。
- [ ] `npm.cmd run build:msix`でMSIXが生成される。
- [ ] MSIXの署名検証が成功する。

## Windowsメディアセッション

- [ ] 権限付きMSIXを起動すると、Client IDやSpotifyログインを求めず現在曲が表示される。
- [ ] 曲名、アーティスト名、ジャケット画像が正しい。
- [ ] 手動で次曲・前曲へ移動すると、通常1秒以内に切り替えが始まる。
- [ ] 再生／一時停止状態が通常1秒以内に反映される。
- [ ] ChromeやYouTubeのメディアセッションが同時に存在してもSpotifyが表示される。
- [ ] Spotifyを終了すると待機画面になり、再起動・再生すると自動で曲表示へ戻る。
- [ ] 待機画面でもホバー時に歯車ボタンと×ボタンが表示される。
- [ ] Spotify Web APIへの定期リクエストが発生しない。

## 曲変更表示

- [ ] 新しいジャケットを読み込んでから、ジャケットと背景バーが同じフレームで切り替わる。
- [ ] フォーカス方式では旧画像を残さず、ジャケット・背景・文字が一枚の表示として動く。
- [ ] スライド方式では0.3.10と同じ28pxの同時スライドと280msの短いクロスフェードになる。
- [ ] 短時間に連続して曲を変更しても、最後に選んだ曲が表示される。
- [ ] 長い曲名とアーティスト名だけがマーキー表示になる。
- [ ] 曲変更中はマーキーが止まり、切り替え後に先頭から再開する。

## ウィンドウと設定

- [ ] 常に最前面、枠なし、透明背景、タスクバー非表示になる。
- [ ] 空いている部分をドラッグして移動できる。
- [ ] 幅180〜520px、高さ72〜180pxでリサイズできる。
- [ ] ホバーすると設定ボタンと終了ボタンが表示される。
- [ ] フォーカスとスライドを切り替え、方式別の時間を保存できる。
- [ ] 背景ぼかしと文字サイズを変更・保存できる。
- [ ] ×ボタンでプロセスが終了する。

## MSIXと自動起動

- [ ] MSIXへ`globalMediaControl`と`runFullTrust`が宣言されている。
- [ ] 自己署名版では公開証明書だけを信頼ストアへ登録してインストールできる。
- [ ] スタートメニューから起動できる。
- [ ] Windowsのスタートアップ一覧へ表示される。
- [ ] 再サインイン時にMSIX版だけが1つ起動する。
- [ ] 更新後も表示設定が維持される。
