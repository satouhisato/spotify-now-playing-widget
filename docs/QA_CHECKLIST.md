# QA Checklist

## 自動確認

- [ ] `npm.cmd run build`が成功する。
- [ ] `src-tauri`で`cargo fmt -- --check`が成功する。
- [ ] `src-tauri`で`cargo test --locked`が成功する。
- [ ] `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`のバージョンが一致する。
- [ ] `npm.cmd run build:msix`でMSIXが生成される。
- [ ] MSIXの署名検証が成功する。

## Windowsメディアセッション

- [ ] 権限付きMSIXを起動すると、Client IDやSpotifyログインを求めず現在曲が表示される。
- [ ] 曲名、アーティスト名、ジャケット画像が正しい。
- [ ] 手動で次曲・前曲へ移動すると、通常1秒以内に切り替えが始まる。
- [ ] 再生／一時停止状態が通常1秒以内に反映される。
- [ ] ChromeやYouTubeのメディアセッションが同時に存在してもSpotifyが表示される。
- [ ] Spotifyを終了すると待機画面になり、再起動・再生すると自動で曲表示へ戻る。
- [ ] 待機画面でもホバー時に歯車ボタンと×ボタンが表示される。
- [ ] Spotify Web APIへの定期リクエストが発生しない。

## 曲変更表示

- [ ] 新しいジャケットを読み込んでから、ジャケットと背景バーが同じフレームで切り替わる。
- [ ] フォーカス方式では旧画像を残さず、ジャケット・背景・文字が一枚の表示として動く。
- [ ] スライド方式では0.3.10と同じ28pxの同時スライドと280msの短いクロスフェードになる。
- [ ] 短時間に連続して曲を変更しても、最後に選んだ曲が表示される。
- [ ] 長い曲名とアーティスト名だけがマーキー表示になる。
- [ ] 曲変更中はマーキーが止まり、切り替え後に先頭から再開する。

## ウィンドウと設定

- [ ] 常に最前面、枠なし、透明背景、タスクバー非表示になる。
- [ ] 空いている部分をドラッグして移動できる。
- [ ] 幅180〜520px、高さ72〜180pxでリサイズできる。
- [ ] ホバーすると設定ボタンと終了ボタンが表示される。
- [ ] 現在の全表示設定へ名前を付けてカスタムプリセットとして保存できる。
- [ ] 保存済みプリセットを適用すると、フォント、ジャケット、帯、背景、文字、動き、再生バーの設定がまとめて復元される。
- [ ] カスタムプリセットを上書き・名前変更・新規作成・削除でき、再起動後も保存内容が残る。
- [ ] カスタムプリセットは最大12件まで保存でき、上限到達後も既存プリセットの適用・上書き・削除ができる。
- [ ] 選択中プリセットを変更すると「変更あり」、内容を適用・保存すると「保存済み」が表示される。
- [ ] カスタムプリセットをJSONへ書き出し、読み込むと既存プリセットを消さず空き枠へ追加される。
- [ ] 不正なJSONを読み込んでも既存プリセットが失われず、読み込み失敗が表示される。
- [ ] 「ウィンドウサイズも含める」を有効にしたプリセットだけが、適用後に保存時の幅・高さへ戻る。
- [ ] サイズを含めないプリセットを適用しても現在のウィンドウサイズが変わらない。
- [ ] プリセット適用時に帯の太さを含む全表示設定が復元される。
- [ ] 「カスタムプリセット」「スタイル」「動きと表示」を個別に折りたたみ、設定画面内のスクロール量を減らせる。
- [ ] フォーカスとスライドを切り替え、方式別の時間を保存できる。
- [ ] 背景ぼかしと50〜140%の文字サイズを変更・保存できる。
- [ ] 日本語の同梱フォント2種類とPC内フォント、ジャケット4種類、背景4種類を切り替えて保存できる。
- [ ] 英数字と日本語のフォントを、Windowsにインストール済みの候補から別々に選択・保存できる。
- [ ] 英数字フォント欄には英数字対応かつ日本語非対応のフォントだけが表示される。
- [ ] 日本語フォント欄には、ひらがな・カタカナ・漢字を表示できるフォントだけが表示される。
- [ ] 英数字と日本語が混在する曲名・アーティスト名で、それぞれ指定したフォントが適用される。
- [ ] 選択済みフォントをWindowsから削除しても、Windows標準または同梱フォントで文字が表示される。
- [ ] ジャケットは縦横比1:1のまま高さ一杯に表示され、帯の太さだけを60〜100%で変更・保存できる。
- [ ] 帯を角丸／四角、右端を通常／フェードから選択・保存できる。
- [ ] フェード時は帯の四角い輪郭を保ったまま、指定位置から右端へ直線的に薄くなる。
- [ ] フェードの長さを15〜60%、強さを40〜100%へ調整・保存できる。
- [ ] ジャケットに外側の影がなく、常にフラットに表示される。
- [ ] アーティスト名の濃さを50〜100%で変更・保存できる。
- [ ] タイトルとアーティストの文字が同じ開始ラインに揃う。
- [ ] 文字配置を左揃え／中央揃えから選択・保存できる。
- [ ] 中央揃えはジャケット右端から帯の右端までの領域を基準にし、短いタイトルとアーティストが同じ中心線に揃う。
- [ ] 中央揃えでも表示幅を超える文字は左端からスクロールし、途中から表示されない。
- [ ] 再生時間バーを表示／非表示から選択・保存できる。
- [ ] 再生時間バーが曲情報の下で中央揃えになり、再生済みの線と現在位置の丸が前後に揺れず滑らかに進む。
- [ ] 再生時間バーの表示／非表示を切り替えても、タイトルとアーティストの中央・左揃え位置が変わらない。
- [ ] 再生時間バーは文字グループと独立して帯の下部に表示される。
- [ ] 再生時間バーが帯の下端へ寄りすぎず、中央の文字グループとの間に自然な余白がある。
- [ ] 長い文字が左へスクロールするとき、文字の開始位置を変えずに左端で自然に消え、硬い切断線が見えない。
- [ ] ダーク／カラー／フロスト／ミラーの各背景で、ジャケットの明暗とぼかし強度に応じて文字色・文字影が読みやすく変化する。
- [ ] カラー背景だけ彩度を100〜160%で変更・保存でき、100%では元のジャケット色に近く、160%では明確に鮮やかになる。
- [ ] カラー彩度を変えるとコントラスト・明度・保護レイヤー・自動配色も不自然に飛ばず連動する。
- [ ] ミラー反射を0〜100%で変更・保存でき、面反射・斜光・ハイライトが連動して自然に弱まり／強まる。
- [ ] 各背景とぼかし強度で、再生済み線・丸・未再生線・光彩が背景へ埋もれない。
- [ ] ジャケットの左右で明暗が異なる場合も、文字が載る中央横長領域に合った文字色とバー色になる。
- [ ] 文字サイズやフォントを変えても、実測した文字グループの下へ再生バーが自然な間隔で配置される。
- [ ] 曲・背景・ぼかしを変更すると、文字色・影・バー色が瞬間的に点滅せず短く滑らかに切り替わる。
- [ ] ぼかしを弱くすると各背景モードの保護レイヤーが強まり、強くすると過剰な暗さ・白さが軽減される。
- [ ] 高さ96px以下で文字・横余白・バー・丸が縮まり、文字やバーが重ならない。
- [ ] 一時停止、再開、シーク、曲変更に再生時間バーが追従する。
- [ ] 再生時間バーの進行色と丸へ、ジャケット由来の読みやすいアクセント色が適用される。
- [ ] ディスクは再生中だけ設定速度で回転し、一時停止すると現在角度で止まる。
- [ ] 角丸、四角、丸ではディスク回転設定を有効にしても回転しない。
- [ ] 丸とディスク表示で帯が円の後ろへ潜り、曲情報との過剰な隙間が見えない。
- [ ] ディスク表示には反射・縁取り・黒い窪みがなく、中央の小さな穴が透明になる。
- [ ] フロスト背景でも曲名とアーティスト名を読み取れる。
- [ ] ミラー背景でジャケット色が透け、上面と縁の反射が見えつつ、写実的・過剰な光沢にならない。
- [ ] ミラー背景の反射と縁取りが、帯の角丸／四角および右端フェードの範囲からはみ出さない。
- [ ] ミラー背景で帯端を通常にしても、右端に縦の区切り線が表示されない。
- [ ] ミラー背景の反射部分に、独立した角丸の縁やガラス板のような輪郭線が見えない。
- [ ] ミラー背景で輪郭線なしでも、大きな面反射・斜光・薄い屈折暗部による鏡面感が確認できる。
- [ ] 設定画面をスクロールして全項目を操作でき、閉じると元のウィンドウサイズへ戻る。
- [ ] ×ボタンでプロセスが終了する。

## MSIXと自動起動

- [ ] MSIXへ`globalMediaControl`と`runFullTrust`が宣言されている。
- [ ] 自己署名版では公開証明書だけを信頼ストアへ登録してインストールできる。
- [ ] スタートメニューから起動できる。
- [ ] Windowsのスタートアップ一覧へ表示される。
- [ ] 再サインイン時にMSIX版だけが1つ起動する。
- [ ] 更新後も表示設定が維持される。
